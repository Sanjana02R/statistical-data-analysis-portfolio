# Space Shuttle Challenger O-Ring Risk Analysis

This project analyzes the relationship between launch temperature and the probability of O-ring damage using logistic regression.

## Objectives

- Analyze Challenger launch data.
- Examine the relationship between launch temperature and O-ring damage.
- Develop a logistic regression model.
- Estimate the probability of O-ring damage.
- Visualize risk at different launch temperatures.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels
- Scikit-learn
