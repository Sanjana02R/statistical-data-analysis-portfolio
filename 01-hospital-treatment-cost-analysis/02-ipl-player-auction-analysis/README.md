# IPL Player Auction Price Analysis

This project analyzes factors influencing IPL player auction prices using simple and multiple linear regression models.

## Objectives

- Develop a simple linear regression model.
- Examine the relationship between batting strike rate and player price.
- Develop a multiple linear regression model.
- Compare regression models.
- Perform hypothesis testing.
- Identify an appropriate set of predictors.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels
- Scikit-learn
